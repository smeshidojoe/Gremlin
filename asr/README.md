# Расшифровка голосовых

Служба, которую зовёт Gremlin, когда в чате включены голосовые. Внутри
Vosk с маленькой русской моделью, снаружи — две ручки:

```
POST /transcribe   multipart/form-data, поле file
200 {"text": "расшифровка", "duration": 12.3}

GET  /health       200 {"ok": true, "model": "vosk-model-small-ru-0.22"}
```

Бот про Vosk ничего не знает: контракт держится на этих двух ручках, и
модель можно заменить на GigaAM, whisper.cpp или что угодно ещё, переписав
только `server.py`. Служба не поднята — бот работает как обычно, просто
без расшифровок.

## Запуск

Модель кладётся в `tools/models/` рядом с моделью нейрофильтра и монтируется
внутрь контейнера. Маленькая русская модель (88 МБ) — с сайта Vosk,
папка `vosk-model-small-ru-0.22`.

Поднимается вместе с ботом:

```bash
docker compose up -d --build asr
```

и включается в `.env`:

```
ASR_URL=http://asr:8080/transcribe
```

После этого в меню чата — «🔍 Распознавание» → «Расшифровывать голосовые».

## Чего ждать от маленькой модели

По собственным замерам Vosk на этой модели ошибается примерно в каждом
пятом слове на чтении вслух и в каждом десятом на чистой речи с микрофона;
на записи из шумного места будет хуже. Для модерации этого хватает: нам
нужны не идеальные субтитры, а слова «казино», «ставки», «работа в
телеграм». Захочется точнее — берите большую модель (`vosk-model-ru-0.42`,
1.8 ГБ, заметно медленнее) или другую распознавалку.

## Сколько ест

Модель держится в памяти целиком: маленькой хватает ~500 МБ. Распознавание
идёт по одной записи за раз — очередь из голосовых не должна отнимать
процессор у самого бота.
