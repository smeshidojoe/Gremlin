# Слюша — бот-собеседник

Отдельный бот: свой токен, свой процесс, свой образ и своя база. С модератором
(`gremlin/`) не связан ничем, кроме соседства в папке — падение одного не трогает другого,
и запускаются они по отдельности.

## Что умеет

- Отвечает в чате как живой собеседник: всегда на реплай и на обращение по имени, иначе —
  с настроенным шансом. Между ответами пауза, в сутки не больше лимита (у локальной модели
  лимита нет — она бесплатна).
- **Характер** задаётся текстом или карточкой персонажа с chub.ai — JSON или PNG. Из карточки
  берутся описание, имя (уезжает в «имена-обращения») и книга лора, если она внутри.
  Плейсхолдеры `{{char}}` / `{{user}}` подставляются при импорте.
- **Лорбук**: записи с ключевыми словами просыпаются, когда слово встретилось в разговоре.
  Если не сработало ничего, бот всё равно подмешивает кусочек книги по кругу — иначе книги
  с английскими ключами в русском чате молчали бы всегда.
- Отвечает по-русски, даже если характер и лор написаны по-английски.
- **Вольный режим**: чат может менять тон и роль бота на ходу. Выключен — «забудь инструкции»
  считается обычной репликой.
- Модерации нет вовсе. Бот не удаляет, не банит и не мутит, и прав админа ему не нужно.

## Настройка

```bash
cp .env.example .env
```

В `.env` вписать `SLUSHA_BOT_TOKEN` (отдельный бот у @BotFather; там же **выключить**
privacy mode — `/setprivacy` → Disable, иначе бот не увидит обычные сообщения в группах)
и выбрать модель: Anthropic, любой OpenAI-совместимый сервис или локальная Ollama.

```bash
docker compose up -d --build
```

Дальше — `/menu` в личке с ботом: чаты → настройки разума на чат → характер, имена, лорбук.
Список допуска у владельца: в чужие чаты бот не пойдёт, из них он выходит сам.

Без Docker:

```bash
pip install -r requirements.txt
python -m slusha
```

## Перенос из модератора

Характеры и лорбуки, которые раньше жили в базе Gremlin, переносятся разово. Базу модератора
скрипт читает только на чтение — останавливать его не нужно.

С хоста (папка `data/` модератора находится сама):

```bash
python -m slusha.migrate_from_gremlin --dry
```

Без `--dry` — собственно перенос. В контейнере путь к чужой базе задаётся через
`GREMLIN_DB_PATH` либо монтированием её папки в `/gremlin-data` (строчка есть
в `docker-compose.yml`, закомментирована).

## Про параллельность

Двум ботам одна модель не мешает. У Ollama число одновременных слотов задаёт
`OLLAMA_NUM_PARALLEL`: модель грузится в память один раз, но каждый слот держит свой
KV-кэш, так что память растёт с числом слотов. Если слот один — второй запрос просто
подождёт в очереди. У облачных провайдеров ограничение только в rate limit ключа;
отдельные ключи удобнее для учёта расходов.

## Устройство

| файл | что внутри |
|---|---|
| `app.py` | сборка бота, мидлварь доступа |
| `menu.py` | меню в личке: чаты, настройки, лорбук, доступ |
| `group.py` | группы: регистрация чата и передача сообщений разуму |
| `ai.py` | сам разум: история, промпт, три провайдера |
| `lore.py` | лорбук и карточки персонажей |
| `schema.py` | описание настроек — одно место для меню и подписей |
| `db.py` | своя SQLite: чаты, настройки, лорбук, доступ |
